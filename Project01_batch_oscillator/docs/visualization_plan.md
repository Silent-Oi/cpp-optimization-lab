# 欠阻尼振子相空间星云

这是 Project01 的图形学入门部分，也是项目核心成果之一。

## 最终画面

每个振子在相空间中绘制为一个粒子：

```text
phase_x = position
phase_y = velocity / omega
```

不同 `omega` 产生不同旋转速度，不同 `zeta` 产生不同收缩速度。大量粒子随时间旋转并向原点坍缩，形成欠阻尼相空间星云。

## 最小技术路线

### 1. 独立 target

新增：

```text
oscillator_visualizer
```

它链接 `oscillator_core`。窗口和绘制依赖只属于这个 target。

### 2. 窗口与像素缓冲

使用 RGFW 建立窗口、事件循环和 CPU RGBA surface。

先完成最小程序：

```text
创建窗口 -> 清空像素 -> 画一个点 -> 显示 -> 关闭窗口
```

不要同时实现完整星云。

### 3. 坐标映射

确定固定相空间范围：

```text
[-x_range, x_range]
[-v_range, v_range]
```

实现从物理坐标到像素坐标的纯函数，并测试原点、边界和裁剪。

不要逐帧自动缩放，否则阻尼收缩会被视觉上抵消。

### 4. 批量状态绘制

创建一批用于显示的欠阻尼振子：

- `omega` 和 `zeta` 使用确定性梯度或分组
- 初始相位具有结构
- 数量以画面密度和运行稳定为准，不要求百万级

每帧：

```text
update_aos_batch(...)
fade_pixel_buffer(...)
draw_particles(...)
present(...)
```

visualizer 必须调用现有核心更新，不复制公式。

### 5. 拖尾与颜色

第一版拖尾通过让旧像素逐帧衰减实现，不保存每个粒子的完整历史。

颜色映射一个固定参数，例如 `omega` 或 `zeta`。颜色只表达参数，不改变物理状态。

### 6. 最小交互

只实现真正帮助观察的功能：

- 暂停 / 继续
- 单步
- 重置
- 退出

参数编辑 UI、复杂菜单和通用 GUI 不属于 Project01。

## 计算时间与显示时间

模拟使用固定 `dt`。显示帧率只决定每秒显示多少次，不改变每一步的物理更新。

窗口事件、像素衰减、粒子绘制和 present 都不进入核心 benchmark。

## 完成标志

- 能稳定打开窗口并显示相空间粒子。
- 粒子随时间旋转并向原点收缩。
- 不同参数组呈现可解释的不同运动。
- 暂停、单步和重置可用。
- 关闭 visualizer 不影响 core、tests 和 benchmark 的构建。
