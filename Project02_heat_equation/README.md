# Project02 — CPU/CUDA Heat Equation

> A planned CPU/CUDA implementation of two-dimensional heat diffusion.

**状态：规划中，尚未实现。**

## 项目成果

实现二维热扩散模拟器，提供可信的 CPU 参考、CUDA 计算后端和温度场显示。两种后端使用相同的物理模型、初始条件和边界条件，并比较数值结果与执行成本。

初始范围采用矩形规则网格、均匀材料、常数热扩散系数和给定温度边界。以明确的离散模型完成计算，不扩展为通用工业热分析软件。

## 路线位置

Project01 的每个振子可以独立更新；本项目的每个网格点需要读取邻居，从而引入空间离散、数据依赖和双缓冲。CPU 版本验证后再引入 CUDA，便于区分数值模型问题与并行实现问题。

热扩散的稳态问题也为后续 Laplace/Poisson 离散和稀疏线性求解提供背景。

## 新增关键知识

- 二维热方程、有限差分、边界条件与显式推进的稳定性。
- 二维网格的线性存储、stencil 邻域访问、双缓冲及内存局部性。
- CUDA kernel、线程映射、host/device 内存、同步和错误检查。
- 数值误差、CPU/GPU 结果比较、设备执行与数据传输的成本。

## 技术阶段

### 1. CPU 参考实现

从二维热方程推导基本离散更新。实现规则网格、初始温度、给定温度边界和双缓冲，确保每一步读取同一旧时间层并写入新时间层。

### 2. 数值验证与稳定性

选用与模型和边界相符的解析解或独立参考，检查温度演化。推导时间步限制，观察越过稳定条件的行为，并在满足稳定性的前提下考察网格和时间步细化对误差的影响。

### 3. 温度场显示

复用已有 CPU 像素显示经验，完成温度到颜色的映射、暂停与重置。物理步长与显示刷新分离，显示作为观察计算过程的手段。

### 4. CUDA 基础实现

在 CPU 结果可信后实现 GPU 后端。先采用简单线程映射和全局内存访问，明确网格边界、设备缓冲区的分配与释放、kernel 执行和同步。与 CPU 参考比较相同物理时刻的结果。

### 5. 执行成本与一次有依据的优化

区分 kernel 执行、数据传输和程序整体耗时；正确处理异步执行的计时。结合 profiling 观察连续访问、重复传输或其他实际瓶颈，选择一个主要因素改进并验证。shared memory 按证据引入，不预设一定更快。

精度变化作为独立取舍分析，不把不同精度导致的性能差异直接归因于硬件或并行方式。

### 6. 稳定版本与后续接口

提供可复现的构建、运行示例和简洁的结果说明。整理模型、网格、计算和显示的职责，理解迭代到稳态与直接求解稳态方程之间的联系，为 Project03 提供可复用的网格与验证案例。

## 完成后的能力

能够独立解释并实现一个带邻域依赖的 PDE 更新程序，定位基本数值和 GPU 执行错误，并说明 CPU/GPU 方案的适用条件与成本。

成果承接 [稀疏 Poisson 求解器](../docs/roadmap.md)，也为后续 GPU 图形实践提供内存、执行和调试经验。
