# Project02 技术路线

路线确认日期：2026-10-09。当前处于第一阶段，数值实现尚未开始。各阶段的具体技术选择随实现证据调整，保持 CPU 参考、数值验证、显示、CUDA、性能分析、稳定版本的顺序。

## 目标与范围

实现二维热扩散模拟器：矩形规则网格、均匀材料、常数热扩散系数、无内部热源、固定温度边界。CPU 和 CUDA 后端推进同一物理问题，显示温度随时间变化。

Project01 的振子互相独立；本项目每个网格点读取邻居，新增空间离散、边界条件、时间步稳定性和同步需求。其稳态问题为 Project03 的 Laplace/Poisson 方程与稀疏线性系统提供背景。

## 六个技术阶段

### 1. 物理模型与 CPU 参考实现

从热量守恒、导热定律和热扩散系数的物理意义理解二维热方程。区分初始条件与边界条件，选取一个简单、与固定边界相容的解析解作为后续参考。

将空间二阶导数写为中心差分、时间导数写为向前差分，得到五点邻域更新。实现二维网格的线性存储、初始化、边界赋值和双缓冲；每一步读取旧时间层，写入新时间层，再交换缓冲区。

**完成边界：** 能解释更新式中各项的含义，完成小网格的一步与连续推进。先确定安全时间步用于运行；系统误差与稳定性分析在第二阶段展开。无需在开始实现前学习完整 PDE 理论或建立通用测试框架。

### 2. 数值验证与稳定性

用常温场和选定解析解检查更新结果，推导与当前离散格式相应的时间步限制。观察越过稳定条件的行为；在满足稳定性的前提下，考察空间与时间离散对误差的影响。

**完成边界：** 有独立参考和可解释的误差指标，能区分实现错误、离散误差与不稳定。验证随程序推进，规模以支持当前判断为限。

### 3. 温度场显示

复用 P1 的窗口和 CPU 像素缓冲经验，完成温度到颜色的映射、暂停、单步与重置。物理推进和显示刷新分离，显示层读取温度而不修改计算状态。

**完成边界：** 能观察热点扩散，交互操作恢复一致状态。第一版采用简单固定色标；不扩展复杂 UI 或三维渲染。

### 4. CUDA 基础实现

在 CPU 结果可信后，确认本机 GPU 与工具链条件并接入 CUDA。采用简单线程映射和全局内存访问，实现设备双缓冲、边界处理、kernel 执行、同步和错误检查，与 CPU 比较相同物理时刻的结果。

**完成边界：** GPU 后端正确运行，能说明线程与网格点的对应关系、设备内存生命周期和时间层之间的依赖。保持相同精度作为初始对照，CPU 构建入口不依赖 CUDA。

### 5. 执行成本与一次有依据的优化

比较少量代表性规模，区分 kernel、数据传输和端到端耗时，正确处理异步执行的计时。结合 profiling 选择一个主要瓶颈改进并验证；shared memory 等技术按证据引入，不预设一定更快。

**完成边界：** 能解释 GPU 收益及其适用规模，完成一次有证据的优化尝试和结果判断，不要求所有规模都获益。精度变化单独分析，不与硬件收益混为一谈。

### 6. 稳定版本与后续衔接

提供可复现的构建、运行示例及简洁结果说明，整理模型、网格、计算与显示的职责。说明固定边界下的稳态问题，以及时间推进到稳态与直接求解稳态方程之间的联系。

**完成边界：** CPU/CUDA 数值结果可对照、温度演化可演示、性能结论有测量范围；能从网格上的邻居关系理解后续稀疏方程结构。

## 实现原则

- 先建立清楚的 CPU 实现和参考结果，再考虑 GPU 与性能优化。
- 网格与物理参数、推进计算、显示保持职责清楚；公共抽象只在确有复用需求时提取。
- 双缓冲是数值语义的一部分：一轮更新统一读取旧时间层。P1 中各线程独立推进分块多个时间步的方式不能直接照搬。
- 当前不加入复杂几何、非均匀材料、隐式求解器或通用工业热分析功能。
- 正确性检查与性能测量用于回答当前问题，不把框架、完整报告或新增实验种类作为阶段完成要求。
