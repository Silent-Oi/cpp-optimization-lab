### 二维热扩散方程的来源

1. 取一个法向沿x方向的圆柱体微元，净流入热量为 Q_静，温度变化 deltaT = Q_静/mc

2. 对时间微分，mc*dT/dt = P_静，P_静为微元热流功率

3. 引入傅里叶导热定律，沿x方向单位面积热流功率与该位置温度对位置的偏导线性相关：q = -k * dT/dx
其中k是导热系数，如果x0处沿x温度升高，那热流是从高温流向低温，即q为负

4. 回到圆柱体，底面面积为A，P_静 = A(q_l - q_r) = Aq(x) - Aq(x+dx) = mc * dT/dt = Adxρ * c * dT/dt
最终得到：-dq/dx = ρ * c * dT/dt

5. 代入傅里叶定律：dT/dt = d^2T/dx^2 * α， 其中α = k/ρc

6. 考虑y轴方向热传导，取正方形微元，x方向以右为正，y方向以上为正。
- x方向净热流功率为P_静x = A(qx_l - qx_r)
- y方向净热流功率为P_静y = A(qy_d - qx_u)
- 系统净热流功率为P_静 = P_静x + P_静y
- 即任意形状系统 P_静 = P边界总流入 - P边界从流出 = intergrate_V(-1 * **q** * **n** * dA)

dT/dt = α * (d^2T/dx^2 + d^2T/dy^2)

### 差分解

思路：根据二维热扩散方程，要想求出温度的更新，就需要求出温度对x和y的二阶导

1. 取原点x0，在 x0+h 和 x0-h 处分别展开 T(x)，保留到2阶
- T(x0+h) = T(x0) + T'(x0)*h + T''(x0)*h*h/2
- T(x0-h) = T(x0) - T'(x0)*h + T''(x0)*h*h/2

2. 求得 Tx''(x0) = [T(x0+h) + T(x0-h) - 2T(x0)]/h*h

3. 同理求得 Ty''(y0)

4. T(x,y,dt) = T(x,y,0) + α * dt * [Tx''(x) + Ty''(y)]

5. T(x,y,t) = T(x,y,0) + α * steps * dt * [Tx''(x) + Ty''(y)]

### 正弦场解析解

正弦场是最简单的温度场，通用扩散解思路也是将初始场分解为正弦场叠加，单独演化最后相加。因此这里先以最基础正弦场为例子来验证差分解的正确性。

1. 取正方形平面，温度 T(x,y,t)。假设外界温度恒定，初始边界温度与外界相同均为T0, 则 θ(x,y,t) = T - T0, θ边界温度为0。

2. θ(x,y,0) = A * sin pi*x/Lx * sin pi*y/Ly

3. 分别求θ对x和y的二阶偏导
- 对x： θ''(x) = -(pi/Lx)^2 * θ
- 对y： θ''(y) = -(pi/Ly)^2 * θ

4. dθ/dt = - α * [(pi/Lx)^2 + (pi/Ly)^2] * θ
一眼看出θ解析解：θ(t) = e^(-λ*t)*θ(0)
