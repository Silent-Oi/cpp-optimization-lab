# 多线程

## 10.25号

多线程也做完了，相比独立的振子，相互关联的二维网格多了一丢丢的交互
但是也只有一丢丢，因为双缓冲的设计，计算本身仍然不需要在线程之间交流
不过也让我学到了不少，**毕竟结果是会影响到其他线程**，这一点我在最开始就没有考虑到。

1. 线程完成任务就会被销毁，无法说创建线程让他停在那里，等待指挥
想到这个是因为我注意到所有线程包括必须全部算完一步之后，一起swap，才能算下一步
于是我就想如果线程能保留任务，那我线程先创建好，再和主线程一起按照step单步计算，算好一下swpa一下
可惜不行

2. std::barrier
这个情况就需要std::barrier来帮忙了，
这个东西的作用就是一个全局计数器，通过 .arrive_and_wait 来数有多少线程在wait
达到设定数量的时候才允许 被计数的线程继续运行

然后设置好线程数量，更新函数结尾里放上 .arrive_and_wait就可以实现每一次计算都等待全部完成了
之后在swap就好了

然后还学到了 std::barrier 可以自动在计数达成时执行设定好的函数
还学到了 这种情况必须声明 执行的函数不会抛出异常，不然的话怕有的线程在中间卡住吧。
