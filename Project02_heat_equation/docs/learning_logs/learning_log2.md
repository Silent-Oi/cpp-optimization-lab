### 误差分析进一步理解

误差不单单是要看误差本身，还要想办法弄清楚怎么有效消除误差，这才是我们做误差实验的真正目的，而不是单纯做个实验看看误差是不是跟我们想的一样的变化趋势。
回到当前项目
时间一阶、空间二阶理论上
也就是dt减半，时间误差减半
两个方向h减半，空间误差变为1/4
接下来做实验验证上面的预期

**一定要有误差分析的意识，而不仅仅是看误差变化**


另一件事是误差不是只看均方根，平均误差就足够的，一定要根据具体情况具体分析
- 相对误差
- 最大误差
- 平均误差
- 等等等
- 还有最重要的一点要进行**误差分析**，判断误差来源，浮点数误差，网格间距带来的误差，时间步带来的误差，温度传导速度带来的误差等等等等


### 误差分析实验后的结论

- 误差来源：空间误差 + 时间误差 + 浮点数误差
- 误差大小：空间误差>>浮点数误差>>时间误差
- 结合上面两点，我们想要分析单一误差，应该用误差的差值来分析，这样可以直接消除其余误差的影响。
我在分析空间误差的时候没有做差也得到了空间误差二阶的结论，这是因为空间误差影响远大于其他误差。
在分析时间误差的时候发现没有按预期减半，甚至是增加的
增加的原因
1. 上面说过的，空间误差和时间误差影响相反
2. 空间误差比时间误差大
举个例子 D1 = 1 - 0.1 = 0.9
D2 = 1 - 0.05 = 0.95

根源是空间误差就分析错了，不能直接看误差绝对值
D1 - D2 = D时间1 - D时间2 = 0.05
D2 = D3 = D时间2 - D时间3 = 0.025
0.05 / 0.025 = 2
时间误差我们预期是: D时间1/D时间2 = 2
可以得到：
D时间1 - D时间2 = D时间2
D时间2 - D时间3 = D时间3
D时间2/D时间3 = 2
与实验观察相同。时间误差与dt线性相关
